Step 1: Start XAMPP
  □ Open XAMPP Control Panel
  □ Start Apache module
  □ Start MySQL module

Step 2: Create Database
  □ Go to http://localhost/phpmyadmin
  □ Click "New" database
  □ Name it: dental_db
  □ Click "Create"

Step 3: Import SQL
  □ Select dental_db database
  □ Click "SQL" tab
  □ Open file: database_setup.sql
  □ Copy entire content
  □ Paste into SQL box
  □ Click "Go"

Step 4: Access Your System
  □ Public site: http://localhost/Dental/index.php
  □ Admin panel: http://localhost/Dental/admin/
